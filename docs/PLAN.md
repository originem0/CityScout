## 需求理解核对

### 核心目标
构建 CityScout 城市分析系统，包含：
1. Web后台管理界面（Next.js 14 + shadcn/ui）
2. 后端API服务（FastAPI + SQLAlchemy 2.0）
3. 爬虫服务（Celery + Playwright）
4. 数据导出与分析功能

### 技术栈确认
- **后端**: Python 3.11+, FastAPI, SQLAlchemy 2.0 (异步), Celery, Redis, PostgreSQL
- **前端**: Next.js 14 (App Router), TypeScript, shadcn/ui, TanStack Query
- **爬虫**: Playwright (浏览器自动化), httpx
- **部署**: Docker Compose

### 关键约束
- 个人使用 + 作品展示
- 需要支持至少10个城市的数据采集
- 需要导出Excel/Markdown/AI报告

## 技术决策记录

### TD-1: 数据库选择 PostgreSQL
**理由**: 支持 JSONB 存储灵活配置，成熟稳定，Docker 部署方便

### TD-2: 使用 SQLAlchemy 2.0 异步模式
**理由**: 与 FastAPI 异步模型配合，性能更好

### TD-3: 爬虫使用 Playwright
**理由**: 58同城等网站有动态渲染，需要浏览器自动化

### TD-4: 任务队列使用 Celery + Redis
**理由**: Python 生态成熟，支持任务监控，可扩展

### TD-5: 前端使用 App Router
**理由**: Next.js 14 推荐方式，Server Components 更好

---

## 风险与缓解

### R-1: 网站反爬
**缓解**:
- 使用 Playwright 模拟真实浏览器
- 控制请求频率（1 req/s）
- 代理池轮换
- User-Agent 轮换
- **对于反爬严格的网站，提供手动导入替代方案（Phase 5.5）**

### R-2: 网站结构变化
**缓解**:
- 爬虫模块化设计，易于调整
- 页面解析与数据处理分离

### R-3: 数据量大导致性能问题
**缓解**:
- 数据库索引优化
- 分页查询
- 定期清理旧数据
