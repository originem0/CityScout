## 一、项目概述

### 1.1 项目背景

求职者需要选择一个适合的南方城市定居和工作，需要综合考虑：
- 工作机会（特定技术方向的岗位数量、薪资）
- 生活成本（房租、日常开销）
- 生活环境（气候、真实居住体验）

### 1.2 项目目标

构建 **CityScout** — 一个完整的城市数据分析系统，包含：
1. **Web后台管理界面** — 配置城市、关键词、查看数据、管理爬虫任务
2. **后端API服务** — 提供数据接口和业务逻辑
3. **爬虫服务** — 异步执行数据采集任务
4. **数据导出** — 生成报告供AI分析

### 1.3 项目定位

- **个人使用** + **作品展示**
- 展示全栈开发能力：前端、后端、爬虫、数据库、部署
- 使用 2025-2026 年最新最实用的技术栈

## 三、功能模块

### 3.1 仪表盘 (Dashboard)

**功能**：
- 数据概览卡片：城市数量、岗位数量、评论数量、最近采集时间
- 爬虫任务状态：运行中、已完成、失败
- 最近采集数据预览
- 快速操作入口

**页面路由**：`/dashboard`

### 3.2 城市管理

**功能**：
- 城市列表（表格展示）
- 新增城市（名称、省份、城市级别、是否启用）
- 编辑城市
- 删除城市（软删除）
- 批量启用/禁用

**页面路由**：`/cities`

### 3.9 手动数据导入

**背景**：Boss直聘、知乎、微博、小红书等平台反爬严格，自动化采集成本高且不稳定。提供手动导入功能作为补充：用户按指南在浏览器中手动搜索，然后将数据导入系统。

**功能一：搜索指南生成**
- 根据已配置的城市和关键词，自动生成各平台的搜索方案
- 提供一键复制搜索关键词
- 提供一键打开搜索 URL（拼接好的）
- 每个平台的搜索技巧和注意事项

**支持平台的搜索指南**：

| 平台 | 搜索策略 | URL 模式 | 提取方式 |
|------|----------|----------|----------|
| **Boss直聘** | 按城市+关键词搜索岗位 | `https://www.zhipin.com/web/geek/job?city={code}&query={keyword}` | 复制列表数据填入模板 |
| **知乎** | 搜索"在{城市}生活/工作是什么体验" | `https://www.zhihu.com/search?type=content&q={query}` | 复制高赞回答 |
| **微博** | 搜索"#{城市}生活#"等话题 | `https://s.weibo.com/weibo?q={query}` | 复制相关微博 |
| **小红书** | 搜索"{城市}租房/工作/生活" | App 内搜索 | 复制笔记内容 |
| **Numbeo** | 查看城市生活成本 | `https://www.numbeo.com/cost-of-living/in/{city}` | 复制费用数据 |

**功能二：数据导入**
- CSV/Excel 批量导入（下载模板 → 填入数据 → 上传导入）
- JSON 导入（程序员友好）
- 表单逐条录入（少量数据时使用）
- 剪贴板粘贴导入（从网页复制表格后直接粘贴）
- 导入时数据校验和预览
- 支持数据去重（按 source_url 判断）
- 导入历史记录

**功能三：数据模板**
- 招聘数据模板 (jobs_template.csv)
- 房租数据模板 (rent_template.csv)
- 论坛评论模板 (comments_template.csv)
- 生活成本模板 (living_cost_template.csv)
- 气候数据模板 (climate_template.csv)

**页面路由**：
- `/manual-import` - 导入主页
- `/manual-import/guide` - 搜索指南
- `/manual-import/upload` - 文件上传导入
- `/manual-import/history` - 导入历史

### 4.2 表结构

#### cities - 城市表
```sql
CREATE TABLE cities (
    id SERIAL PRIMARY KEY,
    name VARCHAR(50) NOT NULL UNIQUE,
    province VARCHAR(50) NOT NULL,
    tier VARCHAR(20) NOT NULL DEFAULT 'tier2',  -- tier1/new_tier1/tier2/tier3
    enabled BOOLEAN NOT NULL DEFAULT TRUE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_cities_enabled ON cities(enabled);
CREATE INDEX idx_cities_tier ON cities(tier);
```

#### keywords - 关键词表
```sql
CREATE TABLE keywords (
    id SERIAL PRIMARY KEY,
    category VARCHAR(30) NOT NULL,  -- job_search/job_exclude/forum_topic
    keyword VARCHAR(100) NOT NULL,
    priority VARCHAR(20) NOT NULL DEFAULT 'extended',  -- core/extended
    enabled BOOLEAN NOT NULL DEFAULT TRUE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(category, keyword)
);

CREATE INDEX idx_keywords_category ON keywords(category);
CREATE INDEX idx_keywords_enabled ON keywords(enabled);
```

#### data_sources - 数据源表
```sql
CREATE TABLE data_sources (
    id SERIAL PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    type VARCHAR(20) NOT NULL,  -- job/rent/forum/public_data
    slug VARCHAR(30) NOT NULL UNIQUE,
    enabled BOOLEAN NOT NULL DEFAULT TRUE,
    priority INTEGER NOT NULL DEFAULT 10,
    config JSONB DEFAULT '{}',
    last_success_at TIMESTAMP WITH TIME ZONE,
    last_error TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
```

#### crawl_tasks - 爬虫任务表
```sql
CREATE TABLE crawl_tasks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    task_type VARCHAR(30) NOT NULL,
    data_source_id INTEGER REFERENCES data_sources(id),
    city_id INTEGER REFERENCES cities(id),
    keyword_id INTEGER REFERENCES keywords(id),
    status VARCHAR(20) NOT NULL DEFAULT 'pending',
    progress INTEGER NOT NULL DEFAULT 0,
    records_count INTEGER NOT NULL DEFAULT 0,
    error_message TEXT,
    celery_task_id VARCHAR(50),
    started_at TIMESTAMP WITH TIME ZONE,
    finished_at TIMESTAMP WITH TIME ZONE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_crawl_tasks_status ON crawl_tasks(status);
CREATE INDEX idx_crawl_tasks_created_at ON crawl_tasks(created_at DESC);
```

#### jobs - 招聘数据表
```sql
CREATE TABLE jobs (
    id SERIAL PRIMARY KEY,
    city_id INTEGER NOT NULL REFERENCES cities(id),
    data_source_id INTEGER NOT NULL REFERENCES data_sources(id),
    task_id UUID REFERENCES crawl_tasks(id),
    job_title VARCHAR(200) NOT NULL,
    company_name VARCHAR(200) NOT NULL,
    salary_min INTEGER,
    salary_max INTEGER,
    salary_unit VARCHAR(10) DEFAULT 'month',  -- month/year/day
    company_size VARCHAR(50),
    job_desc TEXT,
    job_requirements TEXT,
    is_remote BOOLEAN DEFAULT FALSE,
    is_excluded BOOLEAN DEFAULT FALSE,
    exclude_reason VARCHAR(100),
    source_url VARCHAR(500) NOT NULL UNIQUE,
    publish_date DATE,
    crawl_time TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_jobs_city_id ON jobs(city_id);
CREATE INDEX idx_jobs_is_excluded ON jobs(is_excluded);
CREATE INDEX idx_jobs_crawl_time ON jobs(crawl_time DESC);
```

#### rent - 房租数据表
```sql
CREATE TABLE rent (
    id SERIAL PRIMARY KEY,
    city_id INTEGER NOT NULL REFERENCES cities(id),
    data_source_id INTEGER NOT NULL REFERENCES data_sources(id),
    task_id UUID REFERENCES crawl_tasks(id),
    district VARCHAR(100),
    address VARCHAR(300),
    room_type VARCHAR(30) NOT NULL,  -- single/one_bedroom/two_bedroom/whole
    rent_type VARCHAR(20),  -- share/whole
    price INTEGER NOT NULL,
    area DECIMAL(10,2),
    source_url VARCHAR(500) NOT NULL UNIQUE,
    publish_date DATE,
    crawl_time TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_rent_city_id ON rent(city_id);
CREATE INDEX idx_rent_room_type ON rent(room_type);
CREATE INDEX idx_rent_crawl_time ON rent(crawl_time DESC);
```

#### comments - 论坛评论表
```sql
CREATE TABLE comments (
    id SERIAL PRIMARY KEY,
    city_id INTEGER NOT NULL REFERENCES cities(id),
    data_source_id INTEGER NOT NULL REFERENCES data_sources(id),
    task_id UUID REFERENCES crawl_tasks(id),
    keyword_id INTEGER REFERENCES keywords(id),
    title VARCHAR(500),
    content TEXT NOT NULL,
    author VARCHAR(100),
    publish_time TIMESTAMP WITH TIME ZONE,
    likes INTEGER DEFAULT 0,
    replies INTEGER DEFAULT 0,
    source_url VARCHAR(500) NOT NULL UNIQUE,
    crawl_time TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_comments_city_id ON comments(city_id);
CREATE INDEX idx_comments_data_source_id ON comments(data_source_id);
CREATE INDEX idx_comments_crawl_time ON comments(crawl_time DESC);
```

#### living_cost - 生活成本表
```sql
CREATE TABLE living_cost (
    id SERIAL PRIMARY KEY,
    city_id INTEGER NOT NULL REFERENCES cities(id),
    data_source_id INTEGER NOT NULL REFERENCES data_sources(id),
    task_id UUID REFERENCES crawl_tasks(id),
    meal_cost_cheap DECIMAL(10,2),      -- 便宜餐厅一餐
    meal_cost_mid DECIMAL(10,2),        -- 中档餐厅两人
    transport_monthly DECIMAL(10,2),    -- 月交通
    utilities_monthly DECIMAL(10,2),    -- 月水电网
    internet_monthly DECIMAL(10,2),     -- 月网费
    data_date DATE,
    source_url VARCHAR(500),
    crawl_time TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(city_id, data_source_id, data_date)
);

CREATE INDEX idx_living_cost_city_id ON living_cost(city_id);
```

#### climate - 气候数据表
```sql
CREATE TABLE climate (
    id SERIAL PRIMARY KEY,
    city_id INTEGER NOT NULL REFERENCES cities(id),
    data_source_id INTEGER NOT NULL REFERENCES data_sources(id),
    task_id UUID REFERENCES crawl_tasks(id),
    data_year INTEGER NOT NULL,
    winter_avg_temp DECIMAL(5,2),       -- 冬季均温 (12-2月)
    summer_avg_temp DECIMAL(5,2),       -- 夏季均温 (6-8月)
    annual_avg_temp DECIMAL(5,2),       -- 年均温
    annual_rainy_days INTEGER,          -- 年降雨天数
    annual_sunny_days INTEGER,          -- 年晴天天数
    humidity DECIMAL(5,2),              -- 平均湿度
    source_url VARCHAR(500),
    crawl_time TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(city_id, data_year)
);

CREATE INDEX idx_climate_city_id ON climate(city_id);
```

## 八、部署方案

### 8.1 Docker Compose

```yaml
# docker-compose.yml
version: '3.8'

services:
  # 后端 API
  backend:
    build: ./backend
    ports:
      - "8000:8000"
    environment:
      - DATABASE_URL=postgresql://user:pass@db:5432/cityscout
      - REDIS_URL=redis://redis:6379/0
    depends_on:
      - db
      - redis

  # 前端
  frontend:
    build: ./frontend
    ports:
      - "3000:3000"
    environment:
      - NEXT_PUBLIC_API_URL=http://localhost:8000
    depends_on:
      - backend

  # Celery Worker
  celery-worker:
    build: ./backend
    command: celery -A app.tasks.celery_app worker -l info
    environment:
      - DATABASE_URL=postgresql://user:pass@db:5432/cityscout
      - REDIS_URL=redis://redis:6379/0
    depends_on:
      - db
      - redis

  # Celery Beat (定时任务)
  celery-beat:
    build: ./backend
    command: celery -A app.tasks.celery_app beat -l info
    depends_on:
      - celery-worker

  # Flower (任务监控)
  flower:
    build: ./backend
    command: celery -A app.tasks.celery_app flower
    ports:
      - "5555:5555"
    depends_on:
      - celery-worker

  # PostgreSQL
  db:
    image: postgres:16
    volumes:
      - postgres_data:/var/lib/postgresql/data
    environment:
      - POSTGRES_USER=user
      - POSTGRES_PASSWORD=pass
      - POSTGRES_DB=cityscout

  # Redis
  redis:
    image: redis:7-alpine
    volumes:
      - redis_data:/data

volumes:
  postgres_data:
  redis_data:
```

```markdown
# 城市选择深度分析

## 背景
我是一个正在求职的开发者，需要选择一个南方城市定居和工作。我已经收集了多个城市的数据，需要你帮我进行深度分析。

## 我的核心需求
1. **工作**：找到符合我技能的工作机会（Android开发、爬虫、RPA、AI应用等方向）
2. **生活成本**：房租和日常开销要在可承受范围内（月薪的30-40%以内为佳）
3. **气候**：冬天不太冷（冬季均温10°C以上优先）
4. **工作环境**：偏好小公司、远程机会、独立工作

## 我的排除条件
- 岗位要求"沟通协调能力强"、"抗压能力强"、"996"等
- 需要大量社交的工作
- 纯重复性劳动

## 数据文件
以下是我收集的数据：
1. [附上：城市综合对比表.xlsx]
2. [附上：各城市评论汇总.md]

## 请你分析

### 第一部分：结构化数据分析
1. 根据岗位数量和薪资水平，哪些城市工作机会最好？
2. 根据房租和生活成本，哪些城市性价比最高？
3. 计算"薪资/生活成本"比值，排序
4. 综合以上因素，给出前5名城市

### 第二部分：真实评价分析

1. **正面评价**：居民普遍认可的优点是什么？
2. **负面评价**：居民普遍抱怨的问题是什么？
3. **工作环境**：IT行业的真实情况如何？
4. **隐藏信息**：有没有数据看不出来但评论提到的重要信息？

### 第三部分：风险分析
1. 每个候选城市的主要风险是什么？
2. 有没有"数据看起来好但评价很差"的城市？
3. 有没有"数据一般但评价很好"的城市？

### 第四部分：最终建议
1. **首选城市**：推荐哪个城市，理由是什么？
2. **备选城市**：如果首选不行，第二选择是什么？
3. **应该避免的城市**：哪些城市不建议考虑？
4. **下一步行动**：我应该如何进一步验证你的建议？

## 输出格式
请用结构化的方式输出，包含：
- 数据表格（城市排名）
```
