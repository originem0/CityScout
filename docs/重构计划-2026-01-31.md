# CityScout 爬虫系统重构计划

> 状态: **已实施** | 日期: 2026-01-31

## 项目背景

CityScout 是一个城市分析爬虫系统，用于采集招聘、租房、论坛数据以辅助求职决策。本次重构解决了以下核心问题：

1. **反爬应对不全**：无代理IP、无指纹随机化、无验证码应对
2. **可观测性缺失**：进度只有0→50→100三个点，错误信息不可操作
3. **数据采集不完整**：所有爬虫只爬第一页，丢失90%+数据
4. **代码质量问题**：hash()不稳定、裸except吞异常、重复代码

## 详细实施内容

### Phase 1: 基础设施修复

#### 1.1 分页实现
- `BaseCrawler` 新增方法：`find_next_page_url()`, `click_next_page()`, `get_total_pages()`
- `JobCrawler.crawl()` 和 `RentCrawler.crawl()` 重写为多页循环
- 支持配置 `max_pages` (默认5页)
- 页间随机延迟 3-5 秒防反爬
- 进度细粒度报告：每页更新一次

#### 1.2 免费代理池
- `ProxyPool` 类：多源获取 (geonode, proxyscrape)
- 并发健康检查（Semaphore限制10并发）
- 自动轮换：403/429/503 时标记代理失效并切换新代理
- 全局单例模式避免重复初始化
- `_rotate_proxy()` 方法重建浏览器上下文

#### 1.3 hash() 修复
- `f"58_{hash(title)}"` → `f"58job_{hashlib.md5(title.encode()).hexdigest()[:16]}"`
- 跨进程结果一致，避免重复数据

#### 1.4 裸 except 修复
- `safe_get_text()`, `safe_get_attribute()`, `wait_for_selector_safe()` 添加 `logger.debug()` 日志

#### 1.5 截图路径
- 路径改为 `logs/screenshots/{crawler}_{task_id}_{timestamp}.png`
- 自动创建目录

### Phase 2: 可观测性系统

#### 2.1 结构化进度模型 (`progress.py`)
- `CrawlState` 枚举：8个状态 (init → connecting → loading → parsing → saving → paginating → completed/failed)
- `ErrorType` 枚举：9种错误类型
- `CrawlError` 数据类：包含 error_type, message, url, suggestion
- `CrawlProgress` 数据类：包含 percentage 属性（基于页数自动计算）、success_rate、error_summary
- `classify_exception()` 函数：根据异常文本自动分类错误

#### 2.2-2.3 错误分类
- 超时、封禁、验证码、解析错误、网络错误、频率限制、数据库错误、代理错误、未知错误
- 每种错误自动附带可操作建议（`ERROR_SUGGESTIONS` 映射表）

#### 2.4 任务模型扩展
- `current_state`: 当前爬虫状态
- `current_page` / `total_pages`: 分页进度
- `items_found` / `items_failed`: 数据统计
- `error_type`: 错误分类
- `error_details`: JSONB 格式的详细错误信息

### Phase 3: 爬虫逻辑优化

#### 3.1 公共常量
- `CITY_CODES_58`：20个城市代码映射
- 删除 `job_crawler.py` 和 `rent_crawler.py` 中的重复定义

#### 3.2 正则优化
- 预编译5个薪资正则（范围、以上、单值、面议、年薪）
- 预编译经验和学历正则
- 新增 "面议"、"15K以上"、"20-40万/年" 等边界情况处理

#### 3.3 数据去重
- `_save_jobs()` 和 `_save_rents()` 使用 PostgreSQL `INSERT ... ON CONFLICT DO UPDATE`
- 基于 `source_id` 去重：已存在则更新，不存在则插入

### Phase 4: 分析能力增强

#### 4.1 city_stats 整合
- `/analysis/city-comparison` 新增字段：population, gdp, gdp_per_capita, official_avg_salary, living_cost_index, housing_price, avg_temp_year/summer/winter, air_quality_index, sunny_days

#### 4.2-4.3 技能趋势
- 9大技能类别：languages, frontend, backend, databases, devops, ai_ml, bigdata, mobile, tools
- 200+ 技术关键词
- `GET /analysis/skills-trend?city_id=1&limit=30` API
